CENTRE DE CONTRÔLE LAPERLE — VERSION MODIFIÉE
================================================

BASE CONSERVÉE :
Le design, la structure et les modules existants du Centre de Contrôle LAPERLE
ont été conservés.

AJOUTS / VÉRIFICATIONS :
• Proformas : module accessible depuis le menu et le tableau de bord.
• Factures : module dédié avec liste, statuts, ajout, modification, consultation,
  suppression et génération depuis une proforma.
• Paramètres : module dédié pour la configuration de l'entreprise et du profil
  administrateur.
• Les actions Proforma / Facture disposent d'un bouton PDF.
• Les numéros automatiques PF et FAC et le lien N° Proforma restent conservés.
• Recherche, filtres et boutons des modules existants restent conservés.
• Une rangée « Documents commerciaux » permet un accès direct depuis l'accueil.

PARAMÈTRES :
Les informations de l'entreprise sont enregistrées localement dans le navigateur.
La sauvegarde JSON permet de conserver les données de l'application.

PDF :
Le bouton PDF ouvre le document commercial dans une nouvelle fenêtre et lance
l'impression du navigateur. Choisir « Enregistrer au format PDF ».

OUVERTURE :
Décompresser le ZIP puis ouvrir index.html avec Chrome, Edge ou Firefox.
